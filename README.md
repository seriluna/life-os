# LIFE OS MVP 0.1

모바일 우선 한국어 PWA. 현재 버전은 개인 사용성 검증용이며, 서버/로그인/기기간 동기화는 없습니다.

## 실행
- 압축을 풀고 `index.html`을 열어 UI를 볼 수 있습니다. 다만 PWA 설치와 오프라인 캐시는 `file://`에서 동작하지 않습니다.
- PWA 기능까지 테스트하려면 Node.js 설치 후 프로젝트 폴더에서 `npx serve .` 또는 `python -m http.server 8000`을 실행하고 브라우저에서 localhost 주소로 접속하세요.
- 휴대폰에서 설치하려면 HTTPS로 배포하거나, 같은 네트워크에서 접근 가능한 HTTPS 개발 서버를 사용하세요. Android Chrome/Samsung Internet에서는 브라우저 메뉴의 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

## 기능
- 사업/식단/운동/관계/마인드 일일 체크리스트
- 날짜별 기록, 자동 로컬 저장
- 오늘/최근 7일/이번 달 실행률, 영역별 실행률과 병목 안내
- 고객 접촉, 마케팅, 블로그, 제안, 유료 고객, 결제액 기록
- 탄수화물/단백질/지방/체중 기록
- JSON 전체 백업/복원, CSV 내보내기
- PWA manifest 및 오프라인 캐시

## MVP 제한
- 기록은 현재 기기의 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으므로 JSON 백업을 권장합니다.
- 7일/월간 성취율은 실제 기록된 날짜의 계획 행동만 분모에 포함합니다. 기록하지 않은 날은 실패로 계산하지 않습니다.
- 사업 누적 지표는 기록된 날짜들의 합계이며, 매출 통화는 CNY 기준입니다.
- 식단의 탄단지 자동 체크 기준은 탄수화물 목표 ±15g, 단백질 목표보다 10g 이상 낮지 않음, 지방 목표 이하입니다. 건강·영양 평가가 아니라 사용자가 설정한 기록 규칙입니다.
- 다중 사용자 출시 전에는 인증, 서버 데이터베이스, 권한, 개인정보 고지, 데이터 삭제/내보내기, 접근성 및 보안 검토가 필요합니다.


## 식단 · 공복 몸무게 기록
- `오늘 기록` 화면에서 날짜별 식단(아침/점심/저녁/간식)과 공복 몸무게를 수동 입력할 수 있습니다.
- 음식 이름만 입력해도 저장할 수 있으며, 칼로리와 탄수화물·단백질·지방은 선택 입력입니다.
- 기존 날짜의 기록을 불러와 수정하거나 삭제할 수 있습니다.
- 식단/몸무게 기록을 Excel에서 열 수 있는 UTF-8 CSV로 내보낼 수 있습니다.
- 새 기록은 `lifeos.health.logs.v1` localStorage 키에 따로 저장되므로 기존 루틴/사업 기록을 덮어쓰지 않습니다.
- 이 기능도 현재 브라우저 로컬 저장 방식이며 기기 간 동기화는 제공하지 않습니다.

데이터 백업 센터

백업은 안전하게 보관하고, 복원 전에는 파일 정보를 확인해.

01 · BACKUP

전체 기록 백업

프로젝트, 날짜별 기록, 체크리스트 범위, 건강 기록과 목표를 JSON 파일 하나로 보관해.

02 · EXPORT

분석용 데이터 내보내기

Excel 등에서 열어 분석할 수 있는 표 형식 파일이 필요할 때 사용해.

03 · RESTORE

백업 파일 복원

먼저 JSON 파일을 선택해. 파일을 확인한 뒤 복원 버튼을 눌러야 적용돼. 기존 기록은 병합되고 같은 날짜는 백업 파일의 값으로 덮어써.

📄아직 파일을 선택하지 않았어.

복원 전 파일 이름과 크기를 확인해 줘.

개인 식단·운동 기록만 가져오기

건강 기록 전용 JSON을 선택한 뒤 반영해 줘.

🛠️

체크리스트 편집실

실행 항목 추가·수정·삭제는 범위를 확인한 뒤 즉시 저장돼. 영역 이름·설명, 프로젝트 기간, 영역 추가·삭제와 순서 변경은 아래 저장 버튼을 눌러야 반영돼.

EDITOR

실행 항목 수정·삭제 시 날짜만, 직접 지정한 기간, 프로젝트 전체 기간 중 범위를 선택하고 확인 즉시 저장돼. ⠿ 손잡이로 순서를 바꾼 뒤 저장해 줘.

체크리스트 영역

메인 화면과 같은 카드형 구성으로 수정할 수 있어.

저장 전 변경: 영역·기간·순서. 즉시 저장: 실행 항목 추가·수정·삭제(범위 확인 후). 취소한 수정은 반영되지 않아.
